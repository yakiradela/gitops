
## 🏭 מה היית משנה כדי להריץ את זה ב-Production על AWS EKS?

### 1. הקמת תשתית הקלאסטר (IaC) והרשת
* **בפרודקשן:** הייתי משתמש במודול הרשמי של Terraform ל-AWS EKS. המודול מקים VPC מאובטח שכולל Subnets פרטיים וציבוריים, וקלאסטר EKS מנוהל ב-AWS עם Node Groups שיש בו שני מכונות וירטואליות EC2 עם High Availability.

### 2. ניהול Ingress ותעבורת רשת
* **בפרודקשן:** הייתי משתמש ב-AWS Load Balancer Controller, שמנהל את ה-Application Load Balancer (ALB) האמיתי של ענן AWS. ה-ALB מנהל את התעבורה אל ה-Target Groups של הפודים בקלאסטר לפי IP.

### 3. סקיילינג (Scaling)
* **בפרודקשן:** שילוב של Cluster Autoscaler ברמת התשתית כדי להגדיל או להקטין את כמות שרתי ה-EC2 לפי עומס, בנוסף ל-HPA ברמת הפודים.

### 4. ניטור, מתן התראות ואחסון נתונים (Observability)
* **בפרודקשן:** מתקינים את כלי הניטור באמצעות Helm או Argo CD, תוך חיבורם ל-AWS EBS כדי להבטיח שנתוני המטריקות והלוגים לא יימחקו אם הפודים או השרתים עושים ריסטרט.
